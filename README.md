Pré-requisitos

Node.js (v18.0.0 ou superior)
npm (incluso com o Node.js)
VS Code instalado

Como rodar no VS Code

Abra a pasta do projeto no VS Code (File > Open Folder e selecione a pasta trabaio_dw).

Abra o terminal integrado do VS Code usando o atalho Ctrl + ' (ou acesse no menu superior: Terminal > New Terminal).

Instale as dependências executando no terminal:

Bash
npm install
Inicie a aplicação com o comando:

Bash
npm run dev
Segure Ctrl e clique no link http://localhost:5173 exibido no terminal para abrir a aplicação no navegador.
